# Alami Livre — Le Temps

Landing page responsive pour le livre **Le tourisme marocain, Espoir — Tome 1**.

## Publication
Le site est un fichier HTML autonome (index.html) avec CSS et JavaScript intégrés. Il peut être publié avec GitHub Pages ou Cloudflare Pages sans étape de compilation.

## GitHub Pages
Dans le dépôt, ouvrez **Settings → Pages**, choisissez **Deploy from a branch**, sélectionnez **main** et **/(root)**, puis enregistrez.

URL attendue après activation : https://ismailsys.github.io/alami-livre/

## Personnalisation
Le texte, les couleurs et les numéros de contact sont dans index.html. Le visuel de couverture est une interprétation graphique en CSS et non une reproduction exacte de la couverture originale.
